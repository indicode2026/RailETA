RAILETA FINAL DEPLOYMENT

1. Upload all files in this folder to the ROOT of your GitHub repository.
2. Cloudflare Workers -> raileta -> Settings -> Builds:
   Root directory: /
   Build command: none
   Deploy command: npx wrangler deploy
3. Add Worker Secret:
   RAILRADAR_API_KEY = your RailRadar API key
4. Deploy.
5. Test this first:
   https://YOUR-WORKER.workers.dev/health
6. Then test:
   https://YOUR-WORKER.workers.dev/stations/nearby?lat=28.6139&lon=77.2090

Do not put the RailRadar key into app.js, index.html, GitHub, or the ZIP.
